# Atividade 1 - Coleta OpenF1

O script `f1_data_collector.py` coleta sessoes, pilotos e voltas da OpenF1 e salva os dados no MongoDB.

## Execucao

Na raiz do projeto, com o ambiente virtual ativado:

```powershell
python AULA2\atividade1\f1_data_collector.py
```

As dependencias compartilhadas estao em `AULA2/requirements.txt` e a configuracao fica em `AULA2/.env`.
